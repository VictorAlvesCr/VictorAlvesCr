### 🧭 Sobre mim

Sou iniciante em Ciência de Dados e trabalho hoje na área de Operações de CX. Estou construindo minha base em Python, lógica de programação, algoritmos e IA — e já tenho um caminho claro de onde eu quero chegar.

O que mais me atrai é a parte de construção e comunicação: gosto de mexer na engenharia dos dados, garimpar insights, usar IA como ferramenta estatística para prever padrões e, principalmente, ajudar a alavancar a performance do negócio a partir de dados e IA.
